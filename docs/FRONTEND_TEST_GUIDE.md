# 微信小程序前端页面测试指南

## 1. 导入项目到微信开发者工具

### 步骤 1：打开微信开发者工具
- 下载并安装微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
- 打开微信开发者工具，使用微信扫码登录

### 步骤 2：导入项目
1. 点击"+"号或"导入项目"
2. 填写项目信息：
   - **项目名称**：三代互助社区平台
   - **目录**：选择 `C:\Users\Administrator\Desktop\小程序\miniapp`
   - **AppID**：填写您的微信小程序 AppID（测试可使用测试号）
3. 点击"确定"导入项目

### 步骤 3：配置域名（可选）
- 在微信开发者工具中，点击"详情" → "本地设置"
- 勾选"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS"
- 这样可以在开发阶段跳过域名校验

---

## 2. 配置后端 API 地址

### 修改全局配置
打开 `miniapp/app.js`，找到 `globalData` 中的 `apiBaseUrl`，修改为您的后端服务地址：

```javascript
globalData: {
  apiBaseUrl: 'http://localhost:8080' // 改为您的后端地址
}
```

如果使用微信开发者工具的真机调试，需要使用局域网 IP 地址，例如：
```javascript
globalData: {
  apiBaseUrl: 'http://192.168.1.100:8080' // 您的局域网 IP
}
```

## 4. 微信登录功能测试

### 测试步骤：
1. 打开小程序，检查是否自动触发登录
2. 查看控制台，检查 `wx.login` 是否成功获取 code
3. 检查是否成功调用后端登录接口 `/api/v1/auth/wechat-login`
4. 检查是否成功获取 token 并存储到本地
5. 检查后续接口请求是否携带 token

### 预期结果：
- ✅ 成功获取微信登录 code
- ✅ 成功调用后端登录接口
- ✅ 成功获取 token
- ✅ 用户信息正常显示

### 常见问题：
- **问题**：`wx.login` 调用失败
  - **解决**：检查 AppID 是否正确，是否在微信开发者工具中登录

- **问题**：后端登录接口调用失败
  - **解决**：检查后端服务是否启动，API 地址是否正确

- **问题**：token 存储失败
  - **解决**：检查 `wx.setStorageSync` 是否正常

## 5. 微信支付功能测试

### 测试步骤：
1. 创建一个订单
2. 点击支付按钮
3. 检查是否成功调用后端创建订单接口 `/api/v1/wechat-pay/create-order`
4. 检查是否成功获取支付参数（timeStamp, nonceStr, package, signType, paySign）
5. 调用 `wx.requestPayment` 发起支付
6. 支付成功后，检查订单状态是否更新

### 预期结果：
- ✅ 成功创建微信支付订单
- ✅ 成功获取支付参数
- ✅ 成功调起微信支付
- ✅ 支付成功后订单状态更新

### 注意事项：
- 微信支付需要真实的小程序 AppID 和微信支付商户号
- 测试时可以使用微信支付沙箱环境
- 支付回调需要配置服务器接收微信的回调通知

## 6. 调试技巧

### 查看控制台输出
- 在微信开发者工具中，点击"调试器"
- 查看 Console 标签页，检查错误信息
- 查看 Network 标签页，检查接口请求

### 查看页面数据
- 在调试器中，点击"AppData"标签页
- 可以查看当前页面的数据状态

### 断点调试
- 在 Sources 标签页中，找到对应的 JS 文件
- 点击行号设置断点
- 触发对应操作，进行单步调试

### 查看存储数据
- 在调试器中，点击"Storage"标签页
- 可以查看本地存储的数据（token、用户信息等）

## 7. 常见问题解决

### 问题 1：页面无法加载
**可能原因**：
- 文件路径错误
- JSON 配置文件错误
- JS 文件语法错误

**解决方法**：
1. 检查控制台错误信息
2. 检查文件路径是否正确
3. 检查 JSON 配置是否符合规范
4. 检查 JS 语法是否正确

### 问题 2：接口请求失败
**可能原因**：
- 后端服务未启动
- API 地址错误
- 域名未配置或未完成备案
- 网络问题

**解决方法**：
1. 检查后端服务是否启动
2. 检查 API 地址是否正确
3. 在微信开发者工具中勾选"不校验合法域名"
4. 检查网络连接

### 问题 3：数据绑定不生效
**可能原因**：
- WXML 中数据绑定语法错误
- JS 中未正确调用 `setData`

**解决方法**：
1. 检查 WXML 中数据绑定语法 `{{data}}`
2. 检查 JS 中是否正确调用 `this.setData()`
3. 检查数据路径是否正确

### 问题 4：页面样式错乱
**可能原因**：
- WXSS 样式错误
- 样式被覆盖
- 布局问题

**解决方法**：
1. 检查 WXSS 语法是否正确
2. 使用调试器检查元素样式
3. 检查是否有样式冲突
