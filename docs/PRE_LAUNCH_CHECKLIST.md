### 8.2 部署步骤

```bash
# 1. 拉取最新代码
git pull origin main

# 2. 构建Docker镜像
docker build -t mutual-help-platform:latest .

# 3. 执行数据库迁移
./scripts/migrate.sh

# 4. 停止旧服务
docker-compose down

# 5. 启动新服务
docker-compose up -d

# 6. 验证服务健康状态
curl http://localhost:8080/actuator/health

# 7. 检查日志
docker-compose logs -f
```

### 8.3 回滚步骤

```bash
# 1. 停止当前服务
docker-compose down

# 2. 使用上一个版本镜像
docker tag mutual-help-platform:previous mutual-help-platform:latest

# 3. 启动服务
docker-compose up -d

# 4. 验证回滚结果
curl http://localhost:8080/actuator/health
```
